A vending machine flirts with a passing human in a single line: it only takes exact change, but it will drop something sweet — press B4 and let its coils do the flirting. The program validates the line (1–200 characters, one line, valid UTF-8) and writes it to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
